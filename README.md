# Todo App (VIPER + CoreData + Async/Await)

Тестовое задание — приложение для управления списком задач (Todo), реализованное с использованием модульной архитектуры VIPER и асинхронного слоя данных.

## 1. Описание проекта

Приложение позволяет:

- Просматривать список задач
- Создавать новую задачу
- Редактировать существующую
- Удалять задачу
- Отмечать задачу выполненной
- Выполнять поиск по задачам
- Сохранять данные локально
- Загружать начальные данные с удалённого API

Удалённый источник данных: [https://dummyjson.com/todos](https://dummyjson.com/todos)

## 2. Архитектура

Проект построен на архитектуре VIPER.  
Каждый модуль изолирован и содержит:

- View
- Interactor
- Presenter
- Entity
- Router
- ModuleBuilder

Реализованы два модуля:

- `TodoList` — основной экран задач
- `TodoDetails` — экран добавления/редактирования задачи

## 3. Поток данных

1. View инициирует действие → Presenter  
2. Presenter передаёт бизнес-логику → Interactor  
3. Interactor работает через Repository  
4. Repository взаимодействует:
   - с CoreData (локальное хранилище)
   - с NetworkService (удалённый API)  
5. Результат возвращается → Presenter → View

Все тяжёлые операции выполняются в фоновых потоках.  
Обновление UI — строго на главном потоке.

## 4. Асинхронность и многопоточность

Используется:

- Swift Concurrency (`async/await`)
- `Task {}` внутри Interactor
- CoreData через `performBackgroundTask`
- MainActor используется только на уровне UI

Блокирующих операций на главном потоке нет.

## 5. Хранение данных

Используется CoreData.  
Особенности реализации:

- Запись и чтение выполняются в background context
- Политика слияния: `NSMergeByPropertyObjectTrumpMergePolicy`
- Автоматическое объединение изменений в `viewContext`
- Для unit-тестов используется in-memory CoreData стек

## 6. Сетевой слой

- URLSession (async/await)
- JSONDecoder с `.convertFromSnakeCase`
- DTO → Domain маппинг через `TodoMapper`
- Удалённая загрузка выполняется только если локальное хранилище пустое

## 7. Repository Pattern

`TodoRepository` инкапсулирует:

- Локальное хранилище
- Сетевой слой
- Маппинг моделей

Interactor зависит только от `TodoRepositoryProtocol`, что обеспечивает:

- Слабую связанность
- Удобство мокирования
- Простую замену реализации
- Тестируемость

## 8. Поиск

Поиск выполняется локально через NSPredicate:

- Без учёта регистра
- По title и description
- Пустой запрос возвращает полный список

## 9. Тестирование

Покрыты:
